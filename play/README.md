# 掼蛋教练 · 四人对局

你坐**南**家。东家（下家）、北家（对家，你的队友）和西家（上家）由电脑出牌。出牌顺序是 南 → 东 → 北 → 西。

## 运行方式（任选一种）

### 方式一：直接打开（最简单，完全离线）
1. 解压 `guandan-play.zip`。
2. 双击 `guandan-play/index.html`，用 Chrome 或 Edge 打开即可。

这种方式不需要 Node，也不需要联网。三个电脑座位都使用 **decide**（本地规则引擎）。

### 方式二：本地服务器（可以切换到 Jev 机器人）
需要先安装 Node.js 18 或更高版本。

在 Windows 的 PowerShell 里运行：
```powershell
cd guandan-play
$env:TYPESAFE_API_KEY = "你的密钥"   # 可选；不设置时只能用 decide
npm start                            # 等同于 node server.mjs
```
然后在浏览器打开 http://localhost:8787 ，在顶栏的“机器人”里选择 **Jev**。

如果用的是 cmd，设置密钥的命令改为 `set TYPESAFE_API_KEY=你的密钥`。端口可以用 `PORT` 环境变量修改。

- 密钥只保存在服务器进程里，不会发送到网页。
- 服务器只监听本机地址 127.0.0.1。
- Jev 调用失败时，这一手会自动改用 decide 出牌。

### 方式三：iPhone / 手机（网页版，离线可用）
`guandan-play-web/` 是纯静态网页版：只包含网页文件，不含服务器、Jev 和评测数据，适合放到任意 HTTPS 静态托管（例如 GitHub Pages）。
1. 用 iPhone 的 **Safari** 打开网址（必须是 https）。
2. 点底部的“分享”按钮 → **添加到主屏幕** → 添加。
3. 以后从主屏幕图标打开，会全屏运行。打开过一次后，没有网络也能玩（离线缓存）。

手机上的操作：
- **选牌**：点一下选中，再点一下取消；也可以用手指在牌上横向滑动连续选牌。
- **按钮**：底部固定 出牌 / 过 / 提示 / 🚩标记 / 清空。
- **教练提示**：显示在手牌上方，点一下可以展开全文。
- **菜单**：右上角 ☰ 里有速度、升级、明牌、进贡规则、新比赛、分享/复制标记、下载标记。
- **出牌记录**：可以折叠，点 🚩 标记任意一手。
- **导出标记**：iPhone 上建议用“分享/复制标记”。有系统分享时会以 .jsonl 文件分享（可以存到“文件”或发微信），没有时复制到剪贴板，复制也不行时弹出文本框让你手动复制。
- 网页版只能用 decide 机器人。Jev 选项显示为“需电脑本地服务”。
- 横屏、竖屏都可以玩。

## 功能
- **牌桌信息**：显示你的手牌、各家最近一手出的牌、各家剩余张数（5 张及以下标红）、当前级牌（我方和对方的级数）、轮到谁出牌，以及头游到末游的名次。
- **规则校验**：所有出牌都由规则引擎检查，包括牌型、能否压过上一手、轮次。红桃级牌是百搭（标“配”）。“接风”规则也已实现：一家出完后其他人都不要，由他的对家出牌。
- **整副流程**：打完一整副后显示名次、两队级数和下一副的进贡预告。升级按主流规则：双上 +3、头游+三游 +2、头游+末游 +1；打 A 时拿头游且对家不是末游即过 A。
- **进贡 / 还贡 / 抗贡**（第二副起，主流规则，详见仓库根目录 TRIBUTE.md，游戏里菜单“进贡规则”）：手牌上方出现进贡面板。你要进贡时强制牌已自动选好，点“确认进贡”；你要还贡时可还的牌（10 或以下，级牌除外）亮绿框，点一张再“确认还贡”（“建议”= 机器人的选法）。机器人的贡牌公开显示，还贡是暗还（与你有关或开“明牌”时显示牌面）。抗贡时显示提示，由头游先出。关闭“升级”则不进贡。
- **复现**：网址加 `?seed=数字` 可复现同一场比赛（例如 `?seed=1` 第二副你收贡还贡、`?seed=8` 第二副抗贡）。
- **提示**：点“提示”会显示 decide 建议的出法和简短理由，并自动选中对应的牌。
- **复盘**：你每出一手，右侧都会显示是否与教练（decide）一致。不一致时会给出教练的出法和理由，出牌记录里这一手标红。
- **标记**：
  - “🚩 标记此局面”标记当前轮到你的局面，可以先选好你打算出的牌再标记。
  - 出牌记录里每一手（包括电脑出的牌）后面都有 🚩，可以标记那一手。
  - 标记时可以选择“实际出牌是对的”“教练建议是对的”或“不确定”，并写备注。
  - 点“下载标记”会导出 `.jsonl` 文件，格式与 `eval/endgames/*.jsonl` 评测用例一致（包含 levelRank、seat、leading、hands、previous、trickMeta、gold.alts 等），可以直接作为评测用例使用。
  - 标记保存在浏览器的 localStorage 里，刷新页面不会丢失。
- **其他**：“明牌”开关会显示三家电脑的手牌，方便复盘。

## 冒烟测试
```
npm run smoke      # = node src/play/smoke.mjs ：6 场纯电脑对局 + 1 局脚本化人类对局
```

## 文件
- `index.html`、`style.css`、`guandan.bundle.js`：网页本体。规则引擎和 decide 已经打包进 bundle，可以离线运行。
- `manifest.json`、`sw.js`、`icons/`：添加到主屏幕（PWA）和离线缓存用的文件。
- `server.mjs`：可选的本地服务器，提供网页和 `/api/jev` 接口。
- `src/engine`、`src/policy`、`src/search`、`src/belief`、`src/meta`、`src/ml`：规则引擎、decide 和 Jev 的源码。
- `src/play/core.js`：对局逻辑，浏览器和 Node 共用。
- `src/play/jevbridge.mjs`：Jev 接口。
- `src/play/smoke.mjs`：冒烟测试。
