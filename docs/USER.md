# 掼蛋教练 用户手册

## 打开

用浏览器直接打开仓库里的 index.html（file:// 即可，不必起本地服务器，不必安装依赖）。学习中心打开同目录 learn.html，或牌桌顶栏「学习中心」/「训练」。

标题为「掼蛋教练 v12」。脚本带 v=12 缓存戳；改代码后请重新打包并硬刷新。

## 牌桌（index.html）

顶栏：

- 新开局：重新发四手，级牌沿用当前比赛。
- 规则：宿迁（默认，过 A 须双下）或官方 2022（打 A 获胜即过 A）。过 A 三处不同；官方双下为双贡，宿迁双下不进贡。其余进贡共用。
- 进贡模式：开关。开则从 2 打到 A；一局结束后按名次进贡/抗贡，还贡可点选手牌（未选则自动最小），并弹出说明。关则每局只打牌。
- 学习中心 / 训练：进入 learn.html。
- 更多：关键时刻自动弹出建议；出牌动画。

场中：级牌与「红桃级牌 逢人配」。上家 / 队友 / 下家只显示牌背与余张。倒计时 16 秒；轮到你且桌上有人出过牌时超时会自动「不要」。

### 理牌（拖列）

手牌按列排布（默认按点数分列）。按住一张牌拖到：

- 列间隙：该牌单独成新列；
- 另一列：并入该列末尾。

「一键理牌」按点数（王、级牌、A 到 2）重排并恢复默认列。「恢复」只取消选中，不改列序。

### 点选与双击整列

- 单击一张牌：选中或取消该牌（约 300ms 内再点同一张视为双击）。
- 双击一列最上面那张：选中或取消整列。
- 选中后点场中「出牌」，或底栏「采纳建议 / 不要」。

### 桌面出牌

各座位旁有出牌槽（table-plays.js）。有人领出时清槽，再画出各家本轮出的牌或「不要」。场中墩面同步最近一手。

### 提示与采纳

底栏「教练建议」显示推荐牌。「提示」重新算建议（decide）。「采纳建议」按推荐出牌或过牌。理由在右侧抽屉，含牌型说明、硬过滤标签、关键牌估计、阶段（开局/中盘/残局/收尾）。炸弹、同花顺或手牌不超过 2 张时，若开了自动弹出，会出关键建议窗。

### 进贡弹层

进贡模式下一局结束后，引擎：算进贡方向（宿迁双下不进贡；官方双下双贡；否则下游给上游）；进贡方选最大非王；持双大王则该对抗贡。

若需要还贡，弹层先列出每一笔：谁还给谁、进贡了哪张，以及该座位手中合法还贡牌（不超过 10、非王非级牌）做成可点的牌面按钮。

- 你（座位 0）是还贡方时：点选手牌还贡。
- 电脑座位：自动还最小合法牌。
- 未点选就按继续：回退自动还最小合法牌。

确认后弹层改为展示进贡/还贡/抗贡结果，再点继续关闭。

## 学习中心（learn.html）

四个页签：

- 能力雷达：本机六维（牌型识别、合作、炸弹、关键时刻、进贡、还贡）。
- 学习路径：按短板生成一周计划。
- 复盘分析：导出/导入回放 JSON。
- 数据统计：胜率曲线、错误类型、维度。

档案存在本机（键 guandan-coach-user）。换浏览器或清站点数据会丢。
