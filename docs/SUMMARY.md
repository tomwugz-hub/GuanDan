# 总结

掼蛋教练：本机零依赖牌桌 + 启发式教练。规则引擎按宿迁桌规实现；官方 2022 开过 A 三处开关，并编码双下双贡。策略是硬过滤 + 线性分 + 窄束搜索，不是神经网络。

## 已交付

- 规则引擎：牌型识别、比较（5 炸 < 同花顺 < 6 炸）、合法着、领出不能过、逢人配仅红桃级牌且最多 2、顺/同花顺恰好 5、连对/钢板恰好 6。
- 进贡：下游给上游；宿迁双下 0 贡；官方双下双贡（大贡归头游）；头+末同队 1 贡；头+三同队 2 贡；抗贡看进贡方双大王；还贡可指定或自动选不超过 10 的非王非级牌。
- 过 A：宿迁须双下；未双下回 2、头游吃贡；失败回 2。官方开关：打 A 任意获胜即过 A、失败不回 2。
- 策略：decide 挡住 7 类失误，返回中文 reason（含阶段句）与备选。
- 信念 / 搜索：余牌与关键牌估计；候选 = legalMoves + 仅连对/钢板的 extraStructureMoves。
- 教学与档案：六维、错误类型、周计划、回放导入导出、本机存储。
- 牌桌 UI：file:// 打开 index.html；拖列理牌、双击整列、桌面出牌槽、提示/采纳、进贡弹层（还贡可点选手牌）。
- 学习中心：learn.html 雷达 / 路径 / 复盘 / 统计。
- 测试与打包：node 内置测试；pack.mjs 生成 all.js。无第三方包。

## 未交付 / 明确不做

- 没有完整官方进贡分叉。official2022 改过 A 三处，并多一处双下双贡。抗贡集体、红心级牌除外、无不超过 10 则还最小、同点顺时针等官方桌仪不声称。
- 没有真实神经网络。ml/score.js 是手写线性权 weights.json + 特征；tweakWeights 只对非专家项做极小步。不会在浏览器里训练或加载网络。
- 没有服务端、账号、联网对战。档案只在本机。
- 没有第三方包或打包器。浏览器侧是拼接的 all.js + 若干普通 script。
