# 残局评估集（endgame eval）

人工标注的残局局面，用来对比 **旧 `decide`**、**Jev 择着** 与 **gold**。

## 跑评估

在仓库根目录：

```bash
# 仅 decide vs gold（离线，推荐冒烟）
node scripts/run-endgame-eval.mjs --jev=0 --limit=40

# 小样本 + Jev（需 TYPESAFE_API_KEY / TYPESAFE_API_KEY_NEW）
node scripts/run-endgame-eval.mjs --jev=1 --limit=8

# 自定义输出
node scripts/run-endgame-eval.mjs --jev=0 --out=eval/endgames/last-report.md
```

产物：

- `eval/endgames/last-report.md` — 对照表
- `eval/endgames/last-summary.json` — 计数与准确率

无 Key 时 `--jev=1` 仍会跑 decide，Jev 列标记为 fallback（**不会伪造 Jev 结果**）。

## 添加用例

1. 读 `schema.md`。
2. 在 `cases.jsonl` 追加一行 JSON（牌面格式同 `engine/cards.js`：`AS`/`KH`/`10D`/`RJ`）。
3. 尽量给齐四座 `hands`，便于 `decide` 跑通；`previous.cards` 需能 `classify`。
4. 若故意让 decide 与 gold 分歧，设 `"expectJevMayDiffer": true`。
5. 再跑 `--jev=0` 确认报告生成。

## Contrast pairs (DecisionPivot-style)

- `pairs.jsonl`: 30 pairs / 60 cases, generated by `scripts/gen-pairs.py`. Each pair shares `pair_id`; `pivot` names the one decisive detail. A pair scores only if both halves are correct.
- Run: `node scripts/run-pair-eval.mjs [--jev=1] [--startlux=1] [--cases=...]` → `pairs-report.md/.json` (checks gold legality too).
- StartLux adapter (`policy/startluxScore.js`) needs a local llama-server serving a StartLux-Decision GGUF (CC BY-NC weights):
  `llama-server -m StartLux-Decision-v1.1-2B-Instant-Q4_K_M.gguf -c 4096 --parallel 1 --ctx-checkpoints 0 -b 4096 -ub 4096 --port 8081` (`STARTLUX_URL` overrides).
- Jev is non-deterministic run-to-run (±1–2 cases); compare several runs.

## frozen100-pairs.jsonl — TEST-ONLY
`frozen100-pairs.jsonl` (101 contrast pairs / 202 cases, generated by `scripts/gen-frozen100-pairs.py`) is a **frozen test set: never use it for tuning**. Do not change policy, hints, candidate pruning or golds based on its results. Golds were written from mainstream principles before any system was run on it, and legality was checked with `scripts/check-gold-legal.mjs` (engine only, without running decide/Jev). Report results only; to fix a weakness, build a new holdout set that reproduces it.

## frozen-real.jsonl — TEST-ONLY
`frozen-real.jsonl` contains 120 realistic late-game positions extracted from four-seat self-play by `scripts/selfplay-extract.mjs` (seed 7, 80 games, random level ranks, per-seat policy mix of decide/random/greedy). The extractor records positions only, never the moves chosen. Positions were stratified by lead/follow, enemy count, partner count, bomb held and wild held (`scripts/frozen-real-sample.py`; listing used for labelling: `scripts/frozen-real-render.mjs`).
**Golds were hand-labelled from guandan principles** using only the position and the engine's legal-option list (`scripts/frozen-real-labels.py`). decide/Jev outputs were not consulted. Each gold has `gold.alts` (any listed alternative counts, matched strictly by main rank and optional size) and a `confidence` of high/medium/low.
**TEST-ONLY: never tune policy, hints, pruning or golds on this set.** md5s are recorded in `backups/frozen-real.md5`.

## dev-real.jsonl — TUNING / DEV set
`dev-real.jsonl` holds 120 realistic positions built the same way as frozen-real. They come from new self-play: `scripts/selfplay-extract.mjs --games=100 --seed=23 --randomRate=0.12 --maxSeat=15`, which gives the pool `selfplay-pool-dev.jsonl`. Fewer seats play randomly than in frozen-real, and no seat holds more than 15 cards. Positions that overlap frozen-real are excluded (`scripts/dev-real-sample.py`). Labels and confidence marks are in `scripts/dev-real-labels.py`.
**This is the tuning set.** The lookahead round tuned decide and Jev on it. Two golds were widened after re-checking them; `gold_old` and `gold_changed` record the change:
- d075 now also accepts BJ.
- d096 now also accepts RJ.
- d077 (follow round) now accepts [pass, bomb 4]. The original gold was pass only, low confidence ("don't break bomb for FH"). `gold_old` keeps it.

L001–L120 are leads; L121–L150 are follows where an enemy has 1 card. Sampled by `scripts/dev-lead-sample.py` (random.seed 20261041; excludes any position that is also in frozen-real, dev-real or frozen-real2). Labelled blind from principles in `scripts/dev-lead-labels.py`, with confidence marks (80 high / 51 medium / 19 low) and several acceptable golds where moves are equivalent. Two FH alts (L063, L098) were removed before any run because the engine rejected them as illegal. **May be used for tuning**, together with dev-real.

Lead-round outputs (decide + Jev runs, regression) are in `eval/endgames/lead-round/`.
